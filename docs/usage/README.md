# 使用指南

::: tip 总览
本页面将介绍如何开始使用 ExamAware 2。
:::

欢迎使用 ExamAware 2！

## 下载与安装

参照 [快速开始](./quickstart.md) 来快速上手 ExamAware 2。

## 开始使用

我们推荐按照以下流程学习 ExamAware 2 的各类功能。

1. 基础配置：在设置页填写校区/校区编号、考场列表、考试时间；如需网络校时请开启 NTP 同步。
2. 播放场景：启动考试场景，确认大屏展示科目、考试进度与倒计时正常。
3. 插件扩展：如需接入第三方通知、教务系统或定制 UI，可在“插件”页安装 `.ea2x` 插件包。
4. 日志排查：出现异常时，在设置页导出日志并附带操作步骤反馈。

常见问题与配置示例将持续补充，欢迎提出需求。
