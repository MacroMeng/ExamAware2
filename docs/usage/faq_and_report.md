# 常见问题 / 报告问题

::: tip 总览

本页面将介绍使用 ExamAware 2 时出现的常见问题与其解决方式，和您如何在 GitHub 上报告问题。

:::

## 常见问题

### ExamAware 2 无法正常启动该怎么办？

1. 请确保您的计算机满足 ExamAware 2 的 [系统需求](./quickstart.md#系统需求)。
2. 尝试重新安装 ExamAware 2。
3. 若您的计算机满足系统需求，但 ExamAware 2 仍然无法启动，请 [报告问题](#报告问题)。

### 学校铃声与 ExamAware 2 的铃声不同步怎么办？

ExamAware 2 默认使用阿里云 NTP 服务器同步时间。如果您学校的铃声存在偏差，您可以在 `设置 -> 时间同步` 中调整时间偏移。

## 报告问题

如果您在使用 ExamAware 2 时遇到了问题，您可以在 GitHub 上报告问题。请按照以下步骤操作：

### 在 GitHub 上报告 (推荐)

::: tip

您需要至少有一个 GitHub 账号才能报告问题。您可以在互联网上找到如何创建 GitHub 账号的方法。

:::

::: tip

GitHub 有时在中国大陆访问速度较慢，您可以尝试使用代理访问。

:::

1. 访问 [ExamAware 2 | 提交新 Issue](https://github.com/ExamAware/ExamAware2/issues/new)。
2. 按照提示，详细地填写您遇到的问题。
3. 提交这个 Issue。

::: important

如果您不知道如何有效、精准地表述您的问题，我们建议您先阅读 [《提问的智慧》](https://github.com/ryanhanwu/How-To-Ask-Questions-The-Smart-Way/blob/main/README-zh_CN.md)。

:::

::: important

报告问题时，请提供足够的信息，提供越多有效信息越能得到帮助，不要让开发者云里雾里。**您至少应该提供这些信息，否则即使问了也没人能帮上您，且很可能没有人回应您的问题：**

- 您是如何遇到这个问题的，如何稳定复现这个问题
- 您做过什么尝试缓解或修正这个问题
- 系统环境（如操作系统版本等）
- [程序日志](./feat/logging.md)
- 问题发生的截图和录屏
- 错误堆栈信息（如有）

> 在没有错误日志的情况下诊断任何问题无异于闭眼开车
> —— Apache 官方文档 Gettings Started 篇章

:::
