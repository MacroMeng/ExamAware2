# 快速开始

::: tip 总览
本页面将教会你如何在计算机上开始使用 ExamAware 2。
:::

## 系统需求

下载 ExamAware 2 前，请确保您的系统满足如下需求：

### 操作系统与架构

::: danger
本段内容亟需确认。
:::

ExamAware 2 支持以下操作系统：

- Windows 10 1803 或更高版本
- macOS Big Sur11 或更高版本
- Debian 10 (和其衍生版本)

ExamAware 2 只能在这些架构上运行：

- x86_64 架构
- Arm64 架构

::: tip

我们还推荐您的机器满足以下性能要求以流畅运行 ExamAware 2：

- 2 GHz 或更快的处理器
- 4 GiB 以上的 RAM
- 4 GiB 以上的可用磁盘空间
- 支持 DirectX 9 的显卡

:::
